## 0. Статус, версионирование, порядок реализации

### 0.1. Статус

Документ описывает стандартную библиотеку языка Primula: функции прелюдии и модули `std/…`. Библиотека развивается независимо от основной спецификации: добавление, расширение и исправление функций не требует нового выпуска спецификации языка, если не затрагивает ядро (раздел 12 основной спецификации) и грамматику.

Основная спецификация фиксирует только контракт библиотеки: прелюдия доступна без подключения, модули подключаются через `|import("std/…")`, функции детерминированы и не выполняют ввода-вывода (кроме `load_*` ядра). Всё остальное — в этом документе.

### 0.2. Версионирование и совместимость

- Версия библиотеки — `MAJOR.MINOR` (сейчас `1.1-draft`; нумерация согласована с версией языка); пока модули имеют статус `draft`, допускаются несовместимые изменения с записью в разделе 0.4.
- Файл может требовать минимальную версию библиотеки ключом заголовка `primula: {stdlib: "1.1"}`; более старая библиотека — ошибка с указанием недостающей функции.
- После присвоения модулю статуса `stable`: добавление функций и необязательных аргументов — `MINOR`; изменение результата существующей функции — `MAJOR`.
- Результат функции библиотеки при одинаковых аргументах и одинаковой версии библиотеки одинаков (воспроизводимость сборки, раздел 14.3 основной спецификации). Версия библиотеки записывается в отчёт сборки.
- Законодательно изменяемые значения (ставки налогов, календарь праздников) в библиотеку не встроены.

### 0.3. Порядок реализации

Модули независимы и реализуются поэтапно. Каждый этап завершён, когда реализованы функции раздела, тесты по примерам таблиц и поведение для `uk`, `ru`, `en`.

| Этап | Разделы | Содержание | Зависимости |
| --- | --- | --- | --- |
| L1 | 1, 2, 4 | подключение и язык, числа, пропись | — |
| L2 | 3 | деньги, НДС, валюты | L1 |
| L3 | 5 | даты и календарь | L1 (названия месяцев, пропись дат) |
| L4 | 6 | значения с единицами | L1 |
| L5 | 7 | текст и типографика | L1 |
| L6 | 8, 9 | данные, `std/math` | — |

Статус модулей: `draft` — состав и результаты могут меняться; `stable` — изменения только по правилам 0.2. Сейчас все разделы имеют статус `draft`.

### 0.4. Изменения относительно 0.1-draft

- Числа (разделы 2, 3, 4, 9): тип `int` объединён с `decimal`; целое число — `decimal` с масштабом 0 (решение 108 основной спецификации).
- Даты (раздел 5): встроенный тип `datetime` вместо `date` и `days`; арифметика — встроенные операции; добавлены `weeks`, `hours`, `minutes`, `fmt_time`, `fmt_datetime` и заполнители времени.
- `date_words` (раздел 4) принимает `datetime`; время суток игнорируется.
- `std/math` (раздел 9) принимает `decimal`.
- Знак минуса при выводе — U+2212 (раздел 2); `percent` получила `digits`; уточнены `round_to`, `split`.
- Дробные числа: `frac` в `plural` и словаре валют (разделы 1, 3, 7); дроби и `ordinal` в разделе 4.
- Язык вне uk, ru, en и тег с регионом (раздел 1); падежи `month_name` и `weekday`, `workdays(d, 0)`, приоритет и проверка календаря (раздел 5); `qty_range`, `tol`, `convert` (раздел 6); `join_list`, `typography` (раздел 7).

## 1. Подключение и язык

- Прелюдия — функции разделов 2–8 — доступна без подключения; специальные модули — явно: `|import("std/math")`. Имена модулей стандартной библиотеки начинаются с `std/`.
- Функции учитывают язык документа (`uk`, `ru`, `en`); язык переопределяется аргументом `lang=`. Тег с регионом приводится к языку (`uk-UA` → `uk`). Если язык документа другой (`de-DE`), функции работают по `en` и один раз на документ выдают предупреждение с подсказкой `lang=`; неизвестное значение `lang=` — ошибка.
- Словари библиотеки (валюты, единицы, падежные формы, месяцы) расширяются и переопределяются в модуле стилей.
- Законодательно изменяемые значения (ставки налогов, календарь праздников) в библиотеку не встроены: они передаются аргументами или берутся из данных проекта.

Функции модуля стилей для словарей библиотеки (настройки сливаются по слоям, как `numbering`, раздел 11.7 основной спецификации); вызов для уже известного кода или единицы переопределяет только указанные поля:

```python
currency("PLN", "uk", short="zł", units=("злотий", "злоті", "злотих"), frac="злотого", gender="m",
         minor=("грош", "гроші", "грошів"), minor_gender="m", minor_digits=2)
unit("rpm", "uk", symbol="об/хв", quantity="frequency", factor=1/60)
month_names("uk", nom=["січень", …], gen=["січня", …], loc=["січні", …])
typography(percent_space=True, nbsp_short=False, nbsp_words=["в", "у", …])
```

`units`, `minor` — три формы для uk и ru (1, 2–4, 5+), две для en; падежные формы прописью строятся по роду. `frac` — форма родительного падежа единственного числа для дробной суммы («12 500,50 гривні»); для uk и ru обязательна у пользовательских валют, у встроенных задана.

## 2. Числа

| Функция | Результат (uk) |
| --- | --- |
| `num(12500, digits=2)` | «12 500,00» — группы через неразрывный пробел, дробная часть через запятую |
| `num(x, digits=None)` | количество знаков как у значения |
| `percent(20)`, `percent(x, digits=None)` | «20 %» — неразрывный пробел перед знаком (ДСТУ ISO 80000-1); без пробела — `typography(percent_space=False)`; знаки после запятой — как у `num` |
| `round_to(x, step)`, `ceil_to`, `floor_to` | округление до шага: `round_to` — половина от нуля; тип результата как у `x`; `step ≤ 0` — ошибка |
| `round_money(x)` | округление до сотых, половина от нуля |

Отрицательные числа выводятся со знаком минус U+2212 («−1 500,00») для uk, ru и en в `num`, `money`, `percent`, `qty` и столбцах таблиц (ДСТУ ISO 80000-1). Разбор принимает и `-`, и `−`; `str()` и значения ODF остаются на ASCII `-`.

## 3. Деньги и НДС

| Функция | Результат |
| --- | --- |
| `money(12500, "UAH")` | «12 500,00 грн» |
| `money_words(12500, "UAH")` | «дванадцять тисяч п'ятсот гривень 00 копійок» |
| `money_full(12500, "UAH")` | «12 500,00 грн (дванадцять тисяч п'ятсот гривень 00 копійок)» |

- Договорная форма по умолчанию: сначала сумма цифрами, далее в скобках прописью, копейки цифрами.
- Параметры: `kop="digits"` (по умолчанию) или `"words"`; `cap=True` — заглавная первая буква прописи; `currency_style="short"` («грн») или `"full"` («гривень»). При `"full"` форма слова зависит от дробной части: нулевая — форма по целой части («12 500,00 гривень»), иначе `frac` («12 500,50 гривні»); для en дробная сумма — множественное число.
- Валюты: `UAH` (гривна, копейка — женский род), `USD` (доллар США, цент), `EUR` (евро — не склоняется, цент); справочник расширяется в модуле стилей.
- `words(x, "UAH")` — то же, что `money_words(x, "UAH")`.

НДС — ставка передаётся явно (аргументом или из параметров проекта); значения по умолчанию нет:

| Функция | Значение |
| --- | --- |
| `vat(net, rate)` | сумма налога из суммы без налога |
| `with_vat(net, rate)` | сумма с налогом |
| `vat_in(gross, rate)` | налог, выделенный из суммы с налогом: `gross × rate / (100 + rate)` |
| `without_vat(gross, rate)` | сумма без налога |

Результаты округляются до копеек. `split(total, [30, 70])` делит сумму по долям; части округляются до копеек, остаток округления добавляется к последней части, сумма частей равна `total`.

Начальный словарь валют (сокращение стоит после числа через неразрывный пробел для всех языков):

| Код | uk: сокращение / формы / дробная единица | ru | en |
| --- | --- | --- | --- |
| UAH | грн / гривня, гривні, гривень (ж) / копійка, копійки, копійок (ж) | грн / гривна, гривны, гривен / копейка | UAH / hryvnia, hryvnias / kopiyka, kopiykas |
| USD | дол. США / долар США, долари США, доларів США (ч) / цент, центи, центів (ч) | долл. США / доллар США / цент | USD / US dollar, US dollars / cent, cents |
| EUR | євро / євро (незмінне, с) / цент, центи, центів (ч) | евро / евро / цент | EUR / euro, euros / cent, cents |

- Дробная часть любой валюты словаря выводится цифрами («00 центів»), с `kop="words"` — прописью по роду дробной единицы. `currency_style="full"` — форма по числу («12 500,00 гривень»). Неизвестный код — ошибка; расширение — `currency(…)`.
- `float` в `money*`, `vat*`, `split`, `round_money` — ошибка с подсказкой `dec(…)`; `decimal` допустим (целое число — `decimal` с масштабом 0). Все денежные функции округляют до копеек, половина от нуля.
- `with_vat(net, rate)` = `net + vat(net, rate)`; `without_vat(gross, rate)` = `gross − vat_in(gross, rate)`: после округления составляющие всегда дают сумму, приведённую в документе.

## 4. Прописью

| Функция | Результат |
| --- | --- |
| `words(21)` | «двадцять один» |
| `words(21, gender="f")` | «двадцять одна» |
| `words(5, case="gen")` | «п'яти» |
| `words(2.5)` | «дві цілих п'ять десятих» |
| `ordinal(3)` | «третій» |
| `ordinal(21, gender="m", case="gen")` | «двадцять першого» |
| `date_words(date(2026, 10, 12))` | «дванадцятого жовтня дві тисячі двадцять шостого року» (время суток игнорируется) |

`gender`: `"m"`, `"f"`, `"n"`; `case`: `nom`, `gen`, `dat`, `acc`, `ins`, `loc`; языки uk, ru, en (для en род и падеж не применяются).

- `words` — целые до 10¹⁵ − 1; дробная часть до 6 знаков («десятих» … «мільйонних»); отрицательные — «мінус …»; иное — ошибка.
- Дроби: масштаб значения `decimal` (`2.50` → «дві цілих п'ятдесят сотих»; для `float` — кратчайшая десятичная запись). Нулевая дробная часть читается как целое. Масштаб больше 6 после отбрасывания конечных нулей — ошибка. `case=` применяется ко всем частям («двох цілих п'яти десятих»); `gender=` к дробям не применяется: числитель согласуется со словом «ціла/частина» («одна ціла п'ять десятих», «нуль цілих п'ять десятих»). en: «two point five», цифры дробной части по одной (2.05 → «two point zero five»).
- `ordinal(n)`: диапазон 1 … 10¹⁵ − 1; ноль, отрицательные и дробные — ошибка. Склоняется последнее слово. Круглые тысячи, миллионы и миллиарды — сложное слово, формы заданы данными библиотеки. uk (по оценке составителя, подлежит сверке с Правописом 2019): «двотисячний», «тритисячний», «чотиритисячний», «п'ятитисячний», «двадцятип'ятитисячний», «мільйонний», сотни — «двохсотий», «трьохсотий», «чотирьохсотий», «п'ятисотий»; ru — «двухтысячный»; en — «twenty-first», «two thousandth».
- `date_words` для en: «the twelfth of October, two thousand twenty-six».

## 5. Даты и время

Дата и время — встроенный тип `datetime` (раздел 12.3 основной спецификации): момент без пояса, с точностью до секунды; дата — момент в 00:00:00. Отдельных типов `date` и `days` нет. Арифметика — встроенные операции: `dt ± n` — сдвиг на `n` суток (`decimal` или `float`), `dt2 - dt1` — `decimal` суток, `float(dt)` — серийное число.

| Функция | Результат |
| --- | --- |
| `date(2026, 10, 12)`, `datetime(2026, 10, 12, 14, 30, 0)` | конструкторы типа `datetime` |
| `date("2026-10-12")`, `datetime("2026-10-12T14:30")` | разбор строки ISO; строка с поясом — ошибка |
| `dt + 5`, `dt - 5` | сдвиг на 5 суток |
| `weeks(n)`, `hours(n)`, `minutes(n)` | число суток: `dt + weeks(2)`, `dt + hours(36)` |
| `add_months(dt, 1)`, `add_years(dt, 1)` | сдвиг на месяцы и годы (31 → последний день месяца), время сохраняется |
| `dt2 - dt1` | сутки, `decimal` (`date(2026, 10, 12) - date(2026, 10, 7)` → 5) |
| `fmt_date(dt, "short")` | «12.10.2026» |
| `fmt_date(dt, "long")` | «12 жовтня 2026 року» |
| `fmt_date(dt, "contract")` | «12» жовтня 2026 р. |
| `fmt_date(dt, "{d} {month_gen} {y} р.")` | произвольный шаблон |
| `fmt_time(dt, "short")` | «14:30» (с секундами, если они не равны нулю: «14:30:15»); допускается шаблон, форма `long` — ошибка |
| `fmt_datetime(dt, "short")` | «12.10.2026 14:30» |
| `fmt_datetime(dt, "long")` | «12 жовтня 2026 року, 14:30» |
| `fmt_datetime(dt, "{d}.{m}.{y} {hh}:{mi}")` | произвольный шаблон |
| `weekday(dt)`, `weekday(dt, case="acc")`, `month_name(dt, case="gen")` | название дня недели (`nom`, `acc` — «у понеділок»), название месяца (`nom`, `gen`, `loc` — «у жовтні»; иные падежи — ошибка) |

Форматы `short` и `long` у `fmt_date` соответствуют цифровому и словесно-цифровому способам ДСТУ 4163:2020. `fmt_date` учитывает только дату; время суток в шаблоне `fmt_date` (`{hh}` и т. п.) — ошибка с подсказкой `fmt_datetime`. Атрибут `dt.weekday` (основная спецификация, раздел 12.3) — номер дня недели 1–7, понедельник — 1; функция `weekday(dt)` возвращает название.

Рабочие дни: `workdays(d, 5, calendar=cal)`, `is_workday(d, calendar=cal)`. Календарь — данные проекта (`cal = load_yaml("data/calendar-2026.yaml")`): выходные дни недели, праздничные и перенесённые дни. Встроенного календаря нет, потому что состав праздников и их действие меняются законодательно. Время суток аргумента `d` не учитывается; `workdays` возвращает дату (00:00:00).

Количество целых суток между датами: `int(d2 - d1)`. Сравнение моментов — обычные операторы: значения нормализованы до секунды, поэтому `==` точно.

Заполнители шаблона `fmt_date` и `fmt_datetime`: `{d}`, `{dd}` — день («2», «02»); `{m}`, `{mm}` — месяц числом; `{y}`, `{yy}` — год («2026», «26»); `{month}`, `{month_gen}` — название месяца («жовтень», «жовтня»); `{weekday}` — день недели; `{{` и `}}` — литеральные скобки. Только для `fmt_datetime` и `fmt_time`: `{h}`, `{hh}` — час 0–23 («9», «09»); `{mi}` — минута («5», «05» — всегда две цифры); `{s}`, `{ss}` — секунда («7», «07»).

| Формат | uk | ru | en |
| --- | --- | --- | --- |
| `fmt_date` `short` | 12.10.2026 | 12.10.2026 | 2026-10-12 |
| `fmt_date` `long` | 12 жовтня 2026 року | 12 октября 2026 года | 12 October 2026 |
| `fmt_date` `contract` | «12» жовтня 2026 р. | «12» октября 2026 г. | 12 October 2026 |
| `fmt_datetime` `short` | 12.10.2026 14:30 | 12.10.2026 14:30 | 2026-10-12 14:30 |
| `fmt_datetime` `long` | 12 жовтня 2026 року, 14:30 | 12 октября 2026 года, 14:30 | 12 October 2026, 14:30 |

Схема YAML календаря (все ключи необязательны):

```yaml
weekend: [sat, sun]          # еженедельные выходные (по умолчанию)
holidays: [2026-01-01]       # праздничные нерабочие дни (значения datetime без времени)
workdays: [2026-01-10]       # рабочие дни в выходные (переносы)
rest_days: [2026-01-02]      # дополнительные выходные (переносы)
```

- `workdays(d, n, calendar=cal)` — `n` рабочих дней после `d` (сам `d` не считается); `n < 0` — назад; `n = 0` — `d` без изменений (00:00:00), даже если `d` нерабочий. Без `calendar=` рабочими считаются все дни, кроме `sat` и `sun`.
- Приоритет в календаре: `workdays`, `holidays` и `rest_days` главнее `weekend`. Дата одновременно в `workdays` и в `holidays` или `rest_days` — противоречие данных: ошибка проверки календаря.
- Библиотека не переносит выходные автоматически, если праздник приходится на выходной: правила переноса меняются законом и не действуют в военное положение. Все переносы задаются данными явно (`rest_days`, `workdays`).

## 6. Значения с единицами

| Функция | Результат (uk) |
| --- | --- |
| `qty(230, "V")` | «230 В» — неразрывный пробел |
| `qty_range(100, 240, "V")` | «100–240 В» (обе границы неотрицательны: короткое тире без пробелов); при отрицательной границе — «−20…+55 °C» (многоточие, знак у положительной границы, ноль без знака) |
| `qty(50, "Hz", tol=1)` | «(50 ± 1) Гц» — только симметричный допуск; кортеж в `tol=` — ошибка |
| `qty(20, "degC")` | «20 °C» |
| `convert(1.5, "kW", "W")` | 1500: `decimal` для `decimal` (деление — 28 значащих цифр), `float` для `float` |

Обозначения единиц — словарь по языку, расширяемый в модуле стилей. `convert` работает в пределах одной физической величины; несовместимые единицы — ошибка.

Начальный словарь единиц (обозначения ДСТУ ISO 80000 / СИ; uk и ru — кириллицей, en — латиницей):

| Величина | Единицы (код → uk) |
| --- | --- |
| напряжение | `mV` мВ, `V` В, `kV` кВ |
| сила тока | `mA` мА, `A` А |
| мощность | `W` Вт, `kW` кВт, `MW` МВт; полная — `VA` В·А, `kVA` кВ·А (отдельная величина) |
| энергия | `Wh` Вт·год, `kWh` кВт·год |
| частота | `Hz` Гц, `kHz` кГц, `MHz` МГц |
| сопротивление | `Ohm` Ом, `kOhm` кОм, `MOhm` МОм |
| длина | `mm` мм, `cm` см, `m` м, `km` км |
| площадь, объём | `m2` м², `m3` м³, `l` л, `ml` мл |
| масса | `g` г, `kg` кг, `t` т |
| время | `s` с, `min` хв, `h` год |
| давление | `Pa` Па, `kPa` кПа, `MPa` МПа, `bar` бар |
| температура | `degC` °C, `K` К |
| доля | `%` % |

`convert` умножает на отношение коэффициентов в пределах величины (`convert(1, "kVA", "W")` — ошибка); `degC` ↔ `K` — со смещением 273,15. Перед `°C` и `%` — неразрывный пробел (ДСТУ ISO 80000-1): «20 °C».

## 7. Текст

| Функция | Результат |
| --- | --- |
| `plural(n, "день", "дні", "днів", frac="дня")` | форма по числу (uk, ru — три формы; en — две). Дробное `n`: форма `frac`; без неё в uk и ru — ошибка с подсказкой; в en — множественное число. Нулевая дробная часть — форма по целой |
| `join_list(["А", "Б", "В"], last="та")` | «А, Б та В»; союз по умолчанию: uk — «і», ru — «и», en — «and» (без оксфордской запятой); разделитель `sep=", "` |
| `cap(s)` | заглавная первая буква |
| `translit(s)` | транслитерация по языку документа или `lang=`: uk — постановление КМУ № 55 («Київ» → «Kyiv», «зг» → «zgh», особые начальные «є, ї, й, ю, я»); ru — ICAO Doc 9303; en — без изменений |
| `sort_key(s)` | ключ сортировки по алфавиту языка: `sorted(names, key=sort_key)` |
| `nbsp_short(s)` | неразрывный пробел после коротких предлогов и союзов («в», «з», «та», «і») |

Применение `nbsp_short` ко всему тексту включается в модуле стилей: `typography(nbsp_short=True)`.

- `typography(percent_space=True)` — пробел перед `%` (по умолчанию); `False` — «20%».
- `nbsp_words` по умолчанию: uk — а, в, є, і, й, о, у, з, зі, із, та, до, на, по, за, не, ні, що, як, від; ru — а, в, и, к, о, с, у, во, за, из, на, не, ни, по, со, то, что, как, от, до; en — a, an, the, of, to, in, on, at, by, or.
- `typography(nbsp_short=True)` применяет замену ко всему тексту документа при выводе ODT, включая таблицы, колонтитулы, подписи и сноски; не применяется в буквальных блоках, коде, моноширинном ``|`{…}`` и полях Writer. `nbsp_short(s)` — к одной строке. Слова берутся из `nbsp_words` или по языку корневого документа (часть сводного документа со своим языком получает слова корня; язык вне uk, ru, en — слова en). Пробелы после короткого слова заменяются одним неразрывным; граница слова учитывается через границы внутристрочных форм (`в |*{домі}`), поле Writer считается непробельным символом.

## 9. Математика: std/math

`sqrt`, `exp`, `log`, `log10`, `sin`, `cos`, `tan`, `atan2`, `pi`, `e` — результат `float`; `floor`, `ceil` — результат `decimal` с масштабом 0. Функции принимают `decimal` и `float`; `decimal` приводится к `float` автоматически (раздел 12.4 основной спецификации), `floor` и `ceil` от `decimal` вычисляются точно. Состав функций (в частности, тригонометрия) уточняется — открытый вопрос в приложении 4.3 основной спецификации. В документе модуль подключается явно: `|import("std/math")`; в консоли вычислителя (`primula console`, раздел 14.1 основной спецификации) `math` подключён всегда (решение 130).

## 10. QR-коды и кодировки

Решение 137. Построение QR-кода — сотни тысяч шагов, которые в ядре заняли бы секунды, поэтому кодер — функция библиотеки, а форматы поверх него (платёжный QR НБУ и другие) — пользовательские библиотеки модулей.

| Функция | Результат |
| --- | --- |
| `qr_matrix(data, ecc="M", min_version=1, max_version=40, encoding="utf-8")` | QR-код текста в байтовом режиме (ДСТУ ISO/IEC 18004:2019): запись `{version, ecc, mask, size, rows}`; `rows` — строки из `"1"` (тёмный модуль) и `"0"` без тихой зоны |
| `qr_svg(data, ecc=…, min_version=…, max_version=…, encoding=…, size="30mm", quiet=4, circle=0)` | тот же код как строка SVG для `\|img(svg=…)` (решение 131): тёмные модули одним контуром, `viewBox` в модулях с тихой зоной `quiet`, ширина и высота `size`; `circle` > 0 — белый круг этого диаметра (в модулях) в центре |
| `base64url(text, encoding="utf-8")` | Base64URL (RFC 4648, раздел 5) байтов текста, без дополнения `=` |

- Версия — наименьшая из `min_version…max_version`, в которую помещаются байты `data` при уровне коррекции `ecc` (`L`, `M`, `Q`, `H`); не помещаются — ошибка с размером данных. Маска — с наименьшим штрафом по правилам стандарта (первая при равенстве); результат детерминирован.
- `encoding` — `"utf-8"` или `"cp1251"` (Windows-1251); символ, которого нет в кодировке, — ошибка с этим символом.
- Круг `circle` скрывает модули центра; уровень коррекции должен их покрывать (для круга НБУ 17–25 модулей в версиях 10–17 — `M` или `Q`). Изображение в круге (знак) библиотека добавляет в строку SVG сама.
- Неверный уровень, кодировка, диапазон версий, `size`, `quiet` (0–16) или `circle` больше стороны кода — ошибка «значение вне диапазона».
