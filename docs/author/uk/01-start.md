# Перший документ

## Файл

Документ Primula — текстовий файл у кодуванні UTF-8 з розширенням `.prml`. Поруч із документом можуть лежати файли інших видів; їх розрізняє підрозширення:

| Файл | Вид |
| --- | --- |
| `договір.prml` | документ — з нього збирається ODT |
| `умови.f.prml` | фрагмент — частина тексту для вставлення `\|include` |
| `бізнес.m.prml` | модуль — макроси й функції для `\|import` |
| `стилі.s.prml` | модуль стилів |
| `project.p.prml` | файл проєкту |

## Заголовок YAML

Файл починається із заголовка між рядками `---`. У ньому — дані документа, без обчислень:

```prml
---
doc:
  title: "Довідка про співпрацю"
  language: uk-UA
params:
  організація: "ТОВ «Приклад»"
  рік: 2026
---
|(організація) співпрацює з нами з |(рік) року.
```

- `doc:` — метадані ODT: назва, мова, автор, номер, редакція тощо. У тексті вони доступні як `|(doc.title)`. Мова `uk-UA` визначає лапки, перенесення, формат дат і сум прописом.
- `params:` — параметри документа. У тексті й коді вони доступні за іменем. Під час збирання параметр можна замінити: `primula build довідка.prml --param рік=2027`.

Повний перелік ключів — у додатку [«Ключі заголовка»](generated/header-keys.md).

## Текст і абзаци

Абзаци розділяються порожнім рядком. Перехід на новий рядок усередині абзацу — пробіл, тому довгий абзац можна переносити як зручно.

Усе службове починається з `|`. Те, що йде за рискою, визначає конструкцію:

- літера — команда: `|toc`, `|table(…)`;
- `(` — значення виразу: `|(організація)`;
- розділовий знак — коротка форма: `|<` заголовок, `|>` пункт, `|*{…}` напівжирний;
- друга риска — сама риска: `||`.

Виділення всередині рядка (заповнювач у цьому прикладі дає очікуване попередження P2635):

```prml error=P2635
Строк дії — |*{до 31.12.2026}, умови — |/{див. додаток}, код |`{UA-17}.
Назва документа в лапках мови документа: |"{Положення про закупівлі}.
Незаповнене місце в чернетці: |?{прізвище}.
```

Лапки `|"{…}` ставляться за мовою документа («…» для української). Заповнювач `|?{…}` підсвічується й дає попередження під час перевірки: так чернетка не потрапить у випуск непомітно (`--strict` перетворює попередження на помилку).

## Заголовки, пункти, списки

```prml
|<(number=False) Положення про відрядження
|< Загальні положення
|> Положення визначає порядок направлення працівників у відрядження.
|> Строк відрядження не перевищує 30 календарних днів.
|>> Строк може бути продовжено наказом керівника.
|< Документи
Працівник отримує:
|- посвідчення про відрядження;
|- кошторис витрат.
```

- `|<` — заголовок першого рівня, `|<<` — другого, і так до шостого. Номери ставить транслятор; `number=False` — заголовок без номера (назва документа).
- `|>` — пункт, `|>>` — підпункт. Пункти нумеруються в межах розділу: «1.1.», «1.2.», «1.2.1.» (вигляд номерів задає набір стилів: у звіті за ДСТУ 3008 — без крапки в кінці).
- `|-` — маркований елемент списку, `|#` — нумерований; `|--`, `|##` — наступний рівень.

Пункт, заголовок і елемент списку — рядкові форми: вони закінчуються в кінці рядка. Якщо пункт складається з кількох абзаців, його пишуть оточенням і закривають `|end>`:

```prml
|>:
Перший абзац пункту.

Другий абзац того ж пункту.
|end>
```

Список і таблиця одразу після пункту входять до нього; звичайний абзац після пункту — уже не частина пункту.

## Перевірка і збирання

```sh
primula check довідка.prml          # перевірка без запису файлу
primula build довідка.prml          # довідка.odt поруч із вихідним файлом
primula build довідка.prml --pdf    # ще й PDF (потрібен LibreOffice)
```

Перевірка повідомляє про помилки й попередження із зазначенням рядка й стовпця; що з ними робити — на сторінці [«Повідомлення транслятора»](08-messages.md). У Studio ті самі команди — «Перевірити документ» (`Ctrl+Shift+Enter`) і «Зібрати документ» (`F9`); повідомлення відкриває потрібний рядок клацанням.

## Типове оформлення

Якщо документ не називає стилів, застосовується вбудований набір `std/styles/default`: Liberation Sans 11 pt, поля A4, оформлення заголовків, таблиць, виносок. Для ділових документів, листів, інструкцій і звітів у комплекті є готові набори; їх підключає один рядок заголовка, наприклад `styles: [std/styles/business]`. Докладніше — на сторінці [«Стилі»](07-styles.md).
