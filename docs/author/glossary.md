# Глоссарий терминов Primula (ru / uk / en)

Единые термины руководства автора, справки Studio, сообщений транслятора и переводов. Переводчик (человек или модель по зафиксированному промпту этапа 15.5) берёт термин отсюда, а не подбирает синоним. Новый термин сначала вносится сюда. Записи `|…` — конструкции языка, они не переводятся.
