# Стили

Оформление документа задают стили, а не текст: шрифт, отступы, интервалы, рамки таблиц, поля страниц. В тексте пишется только *что* это — заголовок, пункт, реквизиты, — а *как* это выглядит, решает модуль стилей. Поэтому один и тот же документ можно напечатать по-другому, подключив другой набор, а правка оформления не трогает текст.

## Выбор набора

В комплекте транслятора — наборы стилей для типичных документов:

| Набор | Для чего | Основа |
| --- | --- | --- |
| `std/styles/default` | подключается сам, если стили не названы | — |
| `std/styles/business` | договоры, акты, счета, протоколы; ДСТУ 4163:2020 | `default` |
| `std/styles/letter` | служебные письма; ДСТУ 4163:2020 | `business` |
| `std/styles/technical` | руководства, инструкции, технические описания | `default` |
| `std/styles/report` | отчёты в сфере науки и техники; ДСТУ 3008:2015 | `default` |
| `std/styles/compact` | памятки, справки, шпаргалки | `default` |

Документ называет набор одной строкой заголовка:

```prml
---
doc: {title: "Акт", language: uk-UA}
styles: [std/styles/business]
---
|.DocumentTitle: АКТ № 14
```

Основу (`default`) перечислять не нужно: набор сам подключает её. Стили каждого набора, их свойства и шрифт по умолчанию — в приложении [«Стили комплекта»](generated/styles.md); образцы — документы `examples/08-styles` (их можно собрать и посмотреть PDF).

## Применение стилей в тексте

| Запись | Что делает |
| --- | --- |
| `\|.DatePlace: м. Харків` | абзацный стиль для абзаца этой строки |
| `\|.Note:` … `\|end.Note` | абзацный стиль для нескольких абзацев (окружение) |
| `\|.DefinedTerm{Замовник}` | символьный стиль для фрагмента внутри строки |
| `\|*{…}`, `\|/{…}`, ``\|`{…}`` | полужирный, курсив, моноширинный — это тоже символьные стили (`Strong`, `Emphasis`, `Code`) |
| `\|table(style="TableCompact")` | стиль таблицы |
| `\|list("DashList")` | стиль следующего списка |

Имя стиля в `|.Имя` — идентификатор: оно не переводится и не меняется при вычитке текста. Неизвестное имя — ошибка с позицией.

Заголовки, пункты, списки, таблицы и подписи получают стили автоматически — их задаёт привязка конструкций в модуле стилей (`Heading1`…`Heading6`, `Clause`, `BulletList`, `TableGrid`, `TableCaption` …). Поменять стиль конструкции до конца окружения можно командой `|set`:

```prml
|set(list="DashList")
|- перший пункт;
|- другий пункт.
```

Прямое оформление `|fmt(bold=True){…}` тоже есть, но даёт предупреждение: разовое оформление теряется при смене набора, а одинаковые места оформляются по-разному. Если оформление повторяется — заведите стиль.

## Свой модуль стилей

Не правьте наборы комплекта — сделайте свой модуль поверх набора. Он содержит только отличия и называет основу ключом `extends`:

```prml file=styles/компанія.s.prml
---
kind: styles
extends: std/styles/business
defaults: {font: Roboto, size: 11pt}
paragraphs:
  Body:        {line_height: "120%"}
  Реквізити:   {parent: Details, keep_together: true}
characters:
  Акцент:      {bold: true, color: "#1F4E79"}
tables:
  TableServices: {header_background: "#DDE6F0"}
---
```

```prml
---
doc: {title: "Договір", language: uk-UA}
styles: [styles/компанія.s.prml]
---
Текст з |.Акцент{акцентом}.

|.Реквізити: Код ЄДРПОУ 00000000
```

- Документ (или проект) называет только свой модуль: основа и её основа (`business` → `default`) подключаются сами.
- Свойство стиля с тем же именем дополняет стиль набора: `Body: {line_height: "120%"}` меняет только интервал, остальное остаётся от набора.
- Новый стиль наследует существующий через `parent`.
- Шрифт всего документа меняется одной строкой `defaults: {font: …}`. Шрифт должен быть установлен там, где документ открывают или собирают PDF.

Группы стилей в модуле: `paragraphs` (абзацные), `characters` (символьные), `tables`, `lists`, `blocks`, `frames` (размеры и размещение изображений), `pages` (страницы). Свойства — `font`, `size`, `bold`, `align`, `line_height`, `space_before`, `space_after`, `left`, `first_line`, `keep_with_next` и другие; полный перечень — раздел 11.3 спецификации. Подсказки по свойствам и стилям даёт Studio (наведение мыши, `Ctrl+Space`).

## Слои

Если стили названы в нескольких местах, они накладываются слоями, от раннего к позднему:

1. модули из `styles:` проекта;
2. модули, переданные при сборке `--style ФАЙЛ`;
3. модули из `styles:` документа;
4. стили, определённые кодом самого документа.

Более поздний слой дополняет и переопределяет ранние. Основа модуля (`extends`) — слой сразу перед ним. Какие слои реально подключены и откуда взялся каждый стиль, показывает панель «Стили» Studio или `primula check документ.prml --dump-styles`.

## Страницы и колонтитулы

Поля и размер страницы — стиль страницы (`pages:` модуля, по умолчанию `Portrait`; в наборах есть `Landscape`). Колонтитулы задаются в коде модуля стилей или в документе:

```prml
|footer("Portrait"):
|.Footer: Договір № П-2026/017 — сторінка |field.page з |field.pages
|end footer
```

Смена страницы с этого места — `|page(style="Landscape")`, разрыв — `|newpage`.

## Переход с ODT Markdown Kit

Деловой набор Kit 1.2 (`business-styles.yaml`) перенесён в `std/styles/business` и `default` под теми же именами, кроме перечисленных ниже:

| Kit | Primula |
| --- | --- |
| `TocTitle`, `TocEntry` | `ContentsTitle`, `Contents1`…`Contents6` |
| `StrongText`, `EmphasisText`, `UnderlinedText` | `Strong`, `Emphasis`, `Underline` (короткие формы `\|*{}`, `\|/{}`, `\|_{}`) |
| `DraftPlaceholder` | `Placeholder` (короткая форма `\|?{…}`) |
| `BodyRoboto`, `FontCarlito` и подобные | нет: шрифт задаётся `defaults: {font: …}` своего модуля |
| `Recipient`, `LetterSubject`, `Salutation` | в наборе `letter` |
| `Approval` | в `business`, на 100 мм от левого поля (ДСТУ 4163:2020) |
| `NumberedList` с буквами `a)` | `NumberedList` (`1.`, `1.`, `a)`), `LetterList` — буквы языка документа «а)», `LatinLetterList` — «a)» |
| пресеты изображений `Logo`, `Illustration` … | стили фреймов с теми же именами: `\|img(…, style="Logo")` |

Номера пунктов и ссылки в Kit писались текстом; в Primula их ставит транслятор (`|>`, `|@("id")`), а стиль `Clause` применяется к пунктам сам.
