# Параллельные тексты

Окружение `|parallel` ставит рядом два или больше текстов — потоки — и выравнивает по горизонтали начала их смысловых блоков — сегментов. Так пишутся двуязычный договор, протокол разногласий («было / стало»), текст с комментарием на полях. Колонки раздела (`|section(cols=2)`) для этого не годятся: они текут независимо. Таблица годится по виду, но в ней нет понятия «пункт и его перевод»: нумерация, ссылки и язык общие на всю таблицу.

Транслятор выводит `|parallel` таблицей без рамок, но знает потоки: каждый поток нумеруется своими счётчиками, вычисляется на своём языке и сверяется с основным потоком.

## Пример

```prml
---
doc: {title: "Договір / Agreement", identifier: "ДП-2026/017", language: uk-UA}
params:
  ціна: 48000.00
  виконавець: {uk: "ТОВ «Виконавець»", en: "Vykonavets LLC"}
styles: [std/styles/business]
---
|parallel(tracks=[track("uk", lang="uk", title="Українською мовою"), track("en", lang="en", title="In English")],
          gap="8mm", rule="0.3pt solid #999999", parity="translation"):

|segment(span="all"):
|.DocumentTitle: ДОГОВІР № |(doc.identifier) / AGREEMENT No. |(doc.identifier)
|end segment

|segment(id="subject"):
|track("uk"):
|<(id="subject") Предмет договору
|>(id="services") |(getattr(виконавець, track.id)) надає послуги з розроблення документації.
|> Ціна послуг — |(money_full(ціна, "UAH")) (див. |@("services", "label")).
|track("en"):
|<(id="subject") Subject of the Agreement
|>(id="services") |(getattr(виконавець, track.id)) provides the services of developing documentation.
|> The price of the services is |(money_full(ціна, "UAH")) (see |@("services", "label")).
|end segment

|end parallel
```

В украинской колонке сумма выходит «сорок вісім тисяч гривень 00 копійок», ссылка — «п. 1.1»; в английской — «forty-eight thousand hryvnias 00 kopiykas» и «cl. 1.1». Пункты нумеруются в обеих колонках одинаково.

## Потоки

Поток описывается функцией `track(id, …)` в аргументе `tracks=`:

| Аргумент | Что задаёт |
| --- | --- |
| `lang` | язык потока: суммы прописью, даты, кавычки, метки ссылок, проверка орфографии в Writer |
| `title` | название над колонкой; строка названий повторяется на каждой странице |
| `width` | ширина колонки, как у столбца таблицы: `"30%"`, `"60mm"`, `"*"` |
| `primary=True` | основной поток (по умолчанию первый): от него идёт нумерация документа, оглавление, навигация, с ним сверяются остальные |
| `numbered=False` | поток без нумерации: комментарии, примечания на полях |
| `optional=True` | поток может не иметь блока в сегменте — ячейка остаётся пустой |
| `block` | стиль блока для всех ячеек потока (фон, отступы) |

Если нужны только языки, хватает сокращения `langs=["uk", "en"]`. Промежуток между колонками — `gap=`, линия — `rule=`.

Параметры документа общие для всех потоков. Значение на языке потока выбирается кодом: в блоке потока доступна запись `track` (`track.id`, `track.lang`), поэтому `|(getattr(виконавець, track.id))` берёт поле `uk` или `en`.

## Сегменты

Сегмент — строка выравнивания: блок каждого потока начинается на одном уровне, конец — по самому длинному блоку. Сегментом обычно делают раздел договора или пункт.

- **Окружение:** `|segment(id="…"):`, затем блоки потоков `|track("uk"):`, `|track("en"):` и `|end segment`. Блок потока кончается на следующем `|track` или на закрытии сегмента.
- **Строка** — для коротких блоков:

```prml
|parallel(langs=["uk", "en"]):
|segment(id="city") |track("uk"){м. Харків} |track("en"){Kharkiv}
|end parallel
```

- **На всю ширину** — общий текст для всех потоков (название договора, таблица подписей): `|segment(span="all"):` без блоков потоков.

Внутри блока потока пишется обычный текст: заголовки, пункты, списки, таблицы, рисунки, сноски. Нельзя: смена страницы, разделы с колонками, приложения, колонтитулы, оглавление, вложенный `|parallel` (сообщение P5304). Между сегментами допустимы `|newpage` и `|page(…)`: таблица продолжается на новой странице со строкой названий.

Заголовок, оставшийся последним на странице, Writer не переносит к следующему сегменту. Пишите заголовок в одном сегменте с первым пунктом раздела.

## Нумерация, ссылки, сноски

- У каждого потока свои счётчики: при входе в `|parallel` они копируются из документа, после окружения документ продолжает нумерацию основного потока.
- ID внутри потока получает имя потока: `id="services"` в украинском блоке — это `uk.services`, в английском — `en.services`. Поэтому одинаковые `id=` в обоих потоках не конфликтуют.
- `|@("services")` внутри потока ищет цель в своём потоке, затем в основном, затем во всём документе. Цель другого потока пишется полностью: `|@("uk.services")`.
- Сноска неосновного потока получает номер своего потока: в обеих колонках номера одинаковые.
- Заголовки неосновных потоков выглядят как заголовки, но в навигатор Writer и закладки PDF не попадают — там только основной поток.

Оглавление документа берёт заголовки основного потока. Оглавление другого потока — `|toc(track="en")`; название по умолчанию — на языке потока («CONTENTS»):

```prml
|toc(title="ЗМІСТ")
|toc(track="en")
|parallel(langs=["uk", "en"]):
|segment:
|track("uk"):
|< Предмет договору
|track("en"):
|< Subject of the Agreement
|end segment
|end parallel
```

## Проверка соответствия

Аргумент `parity=` сверяет каждый нумеруемый поток с основным в каждом сегменте:

| Профиль | Что проверяется |
| --- | --- |
| `structure` (по умолчанию) | есть ли блок каждого обязательного потока; последовательность заголовков, пунктов, элементов списков, таблиц, рисунков, примечаний |
| `translation` | то же, а также ID, цели ссылок, имена параметров в `\|(…)`, числа и адреса в тексте, счётчики потоков в конце |
| `none` | ничего |

Сегмент может задать свой профиль: `|segment(id="idiom", parity="none")` — для вольного перевода. Расхождения — предупреждения P5310–P5315; с `--strict` они становятся ошибками.

```prml error=P5311
|parallel(langs=["uk", "en"], parity="translation"):
|segment(id="term") |track("uk"){Строк — 5 днів.} |track("en"){The term is 7 days.}
|end parallel
```

## Перевод: заготовки, подтверждение, актуальность

Когда документ переводится, удобно вести состояние каждого блока:

1. **Заготовки.** `primula parallel договір.prml --stub --track en` дописывает в сегменты без английского блока копию структуры основного блока с заполнителями `|?{…}`. Заполнители — предупреждения, с `--strict` — ошибки, поэтому незаполненный перевод не уйдёт в выпуск.
2. **Подтверждение.** Проверенный перевод фиксируется: `primula parallel договір.prml --stamp --track en --status reviewed` записывает в блоки `status="reviewed"` и `rev="…/…"` — хеши текста основного блока и самого перевода. `--segment ID` подтверждает только названные сегменты.
3. **Изменение оригинала.** Если после подтверждения изменён украинский текст, `check` выдаёт P5320 «перевод устарел»; если изменён сам перевод — P5321. Предупреждение остаётся, пока перевод не исправлен и не подтверждён снова.
4. **Перед выпуском.** `primula parallel договір.prml --check-status reviewed` завершается ошибкой, если какой-то блок не в этом состоянии или устарел.

В Studio те же действия — в меню «Сборка → Параллельные потоки» и в контекстном меню редактора («Подтвердить перевод сегмента …» для блока под курсором). Панель «Структура» показывает сегменты и блоки потоков со статусом и отмечает устаревшие.

Хеш считается по тексту блока без комментариев и лишних пробелов, поэтому переформатирование не делает перевод устаревшим. Выражения `|(…)` входят в хеш как записаны: смена значения параметра перевод не устаревает — значения общие для потоков.

## Протокол разногласий

Три потока: редакция поставщика (необязательная — нового пункта в ней нет), редакция покупателя (основной поток) и комментарий юриста (без нумерации, узкая колонка). Номера пунктов договора пишутся явно:

```prml
|parallel(tracks=[track("old", title="Редакція Постачальника", optional=True),
                  track("new", title="Редакція Покупця", primary=True),
                  track("note", title="Коментар", width="30%", numbered=False, optional=True)]):
|segment(id="p-4-2"):
|track("old"):
|*{4.2.} Оплата здійснюється протягом 5 банківських днів.
|track("new"):
|*{4.2.} Оплата здійснюється протягом 30 календарних днів.
|track("note"):
|.SmallPrint: Відстрочку погоджено листом від 12.10.2026.
|end segment
|segment(id="p-4-3"):
|track("new"):
|*{4.3.} Покупець має право на дострокову оплату.
|end segment
|end parallel
```

Полные примеры — `examples/09-parallel/agreement.prml` (двуязычный договор с подтверждёнными переводами) и `protocol.prml`.

## Стили

Таблица вывода — стиль `ParallelTable` (без рамок), строка названий потоков — `ParallelHeader`; оба есть во всех наборах комплекта (приложение [стили комплекта](generated/styles.md)). Свои имена задаются в модуле стилей: `structure_styles(parallel_table="…", parallel_header="…")` или аргументом `style=` у `|parallel`.
