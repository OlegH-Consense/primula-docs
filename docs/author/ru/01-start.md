# Первый документ

## Файл

Документ Primula — текстовый файл в кодировке UTF-8 с расширением `.prml`. Рядом с документом могут лежать файлы других видов; их различает подрасширение:

| Файл | Вид |
| --- | --- |
| `договір.prml` | документ — из него собирается ODT |
| `умови.f.prml` | фрагмент — часть текста для вставки `\|include` |
| `бізнес.m.prml` | модуль — макросы и функции для `\|import` |
| `стилі.s.prml` | модуль стилей |
| `project.p.prml` | файл проекта |

## Заголовок YAML

Файл начинается с заголовка между строками `---`. В нём — данные документа, без вычислений:

```prml
---
doc:
  title: "Довідка про співпрацю"
  language: uk-UA
params:
  організація: "ТОВ «Приклад»"
  рік: 2026
---
|(організація) співпрацює з нами з |(рік) року.
```

- `doc:` — метаданные ODT: название, язык, автор, номер, редакция и т. д. В тексте они доступны как `|(doc.title)`. Язык `uk-UA` определяет кавычки, переносы, формат дат и сумм прописью.
- `params:` — параметры документа. В тексте и коде они доступны по имени. При сборке параметр можно заменить: `primula build довідка.prml --param рік=2027`.

Полный перечень ключей — в приложении [«Ключи заголовка»](generated/header-keys.md).

## Текст и абзацы

Абзацы разделяются пустой строкой. Перевод строки внутри абзаца — пробел, поэтому длинный абзац можно переносить как удобно.

Всё служебное начинается с `|`. Что идёт за чертой, определяет конструкцию:

- буква — команда: `|toc`, `|table(…)`;
- `(` — значение выражения: `|(організація)`;
- знак препинания — короткая форма: `|<` заголовок, `|>` пункт, `|*{…}` полужирный;
- вторая черта — сама черта: `||`.

Выделения внутри строки (заполнитель в этом примере даёт ожидаемое предупреждение P2635):

```prml error=P2635
Строк дії — |*{до 31.12.2026}, умови — |/{див. додаток}, код |`{UA-17}.
Назва документа в лапках мови документа: |"{Положення про закупівлі}.
Незаповнене місце в чернетці: |?{прізвище}.
```

Кавычки `|"{…}` ставятся по языку документа («…» для украинского). Заполнитель `|?{…}` подсвечивается и даёт предупреждение при проверке: так черновик не уйдёт в выпуск незаметно (`--strict` превращает предупреждение в ошибку).

## Заголовки, пункты, списки

```prml
|<(number=False) Положення про відрядження
|< Загальні положення
|> Положення визначає порядок направлення працівників у відрядження.
|> Строк відрядження не перевищує 30 календарних днів.
|>> Строк може бути продовжено наказом керівника.
|< Документи
Працівник отримує:
|- посвідчення про відрядження;
|- кошторис витрат.
```

- `|<` — заголовок первого уровня, `|<<` — второго, и так до шести. Номера ставит транслятор; `number=False` — заголовок без номера (название документа).
- `|>` — пункт, `|>>` — подпункт. Пункты нумеруются внутри раздела: «1.1.», «1.2.», «1.2.1.» (вид номеров задаёт набор стилей: в отчёте по ДСТУ 3008 — без точки в конце).
- `|-` — маркированный элемент списка, `|#` — нумерованный; `|--`, `|##` — следующий уровень.

Пункт, заголовок и элемент списка — строчные формы: они заканчиваются в конце строки. Если пункт состоит из нескольких абзацев, его пишут окружением и закрывают `|end>`:

```prml
|>:
Перший абзац пункту.

Другий абзац того ж пункту.
|end>
```

Список и таблица сразу после пункта входят в него; обычный абзац после пункта — уже не часть пункта.

## Проверка и сборка

```sh
primula check довідка.prml          # проверка без записи файла
primula build довідка.prml          # довідка.odt рядом с исходником
primula build довідка.prml --pdf    # ещё и PDF (нужен LibreOffice)
```

Проверка сообщает об ошибках и предупреждениях с указанием строки и столбца; что делать с ними — на странице [«Сообщения транслятора»](08-messages.md). В Studio те же команды — «Проверить документ» (`Ctrl+Shift+Enter`) и «Собрать документ» (`F9`); сообщение открывает нужную строку щелчком.

## Оформление по умолчанию

Если документ не называет стили, применяется встроенный набор `std/styles/default`: Liberation Sans 11 pt, поля A4, оформление заголовков, таблиц, сносок. Для деловых документов, писем, инструкций и отчётов в комплекте есть готовые наборы; их подключает одна строка заголовка, например `styles: [std/styles/business]`. Подробнее — на странице [«Стили»](07-styles.md).
