# Акт и таблицы с итогами

Таблица — окружение `|table(…):` … `|end table`. Строка начинается с `|:`, ячейки разделяет `|&`. Транслятор считает итоги по формулам, проверяет число ячеек в строках и оформляет числа и суммы по языку документа.

## Простая таблица

```prml
|table(cols=["40%", "*"], header=1):
|: Показник |& Значення
|: Строк поставки |& 10 робочих днів
|: Місце поставки |& склад Покупця
|end table
```

- `header=1` — одна строка заголовка; на следующих страницах она повторяется.
- `cols` — ширины столбцов: `"40mm"` — фиксированная, `"30%"` — доля таблицы, `"*"` — остаток, `"auto"` — по содержимому, `"20mm..60mm"` — по содержимому в пределах.
- Число ячеек каждой строки должно совпадать с числом столбцов; лишняя или недостающая ячейка — ошибка с номером строки. Пустая ячейка — `|&` без текста.

## Акт: строки из данных и итог

Пусть позиции акта лежат в CSV:

```csv file=data/позиції.csv
назва,кількість,ціна
Налаштування обладнання,2,1500.00
Навчання персоналу,1,2400.00
Виїзд спеціаліста,3,350.00
```

Таблица акта с итогом и НДС:

```prml
|code:
позиції = load_csv("data/позиції.csv", types={"кількість": "decimal", "ціна": "money"})
|end
|table(id="т-акт", caption="Перелік наданих послуг", header=1, footer=3, cols=["10mm", "*", col("18mm", id="к", type="decimal", align="right"), col("26mm", id="ц", type="money", align="right"), col("30mm", id="с", type="money", currency="UAH", align="right")]):
|: № |& Послуга |& К-сть |& Ціна |& Сума
|for(н, п in enumerate(позиції, 1)):
|: |(н) |& |(п.назва) |& |(п.кількість) |& |(п.ціна) |& |=(this_row("к") * this_row("ц"))
|endfor
|:|&(span=4, align="right") Разом без ПДВ |& |=(sum(column("с", rows=body_rows())))
|:|&(span=4, align="right") ПДВ 20 % |& |=(round(cell(len(позиції) + 2, "с") * dec("0.20"), 2))
|:|&(span=4, align="right") |*{Усього} |& |=(cell(len(позиції) + 2, "с") + cell(len(позиції) + 3, "с"))
|end table
Див. |@("т-акт", "label").
```

Что здесь происходит:

- `load_csv` читает файл; `types=` объявляет типы столбцов, иначе всё читается строками. Путь — относительно документа и не выходит за корень проекта. Так же работают `load_yaml` и `load_json`.
- `col(ширина, id=…, type=…, currency=…, align=…)` описывает столбец. `id` — имя столбца в формулах. `type="money"` выводит значение с двумя знаками («1 500,00»), `currency="UAH"` добавляет «грн», `type="decimal"` — число с разделителями групп.
- `|for(…):` … `|endfor` повторяет строку для каждой позиции.
- `|=(…)` — формула ячейки. Она вычисляется, когда известны все обычные ячейки: `this_row("к")` — значение столбца `к` этой строки, `column("с", rows=body_rows())` — столбец по строкам тела (без заголовка и итогов), `cell(строка, столбец)` — ячейка по номеру строки (с 1, считая заголовок) и столбцу.
- `footer=3` — три строки итогов; они не входят в `body_rows()`.
- `|:|&(span=4, align="right")` — аргументы первой ячейки пишутся вплотную после `|:`; `span=4` объединяет четыре столбца.
- `caption=` и `id=` дают подпись «Таблиця 1 — Перелік наданих послуг» и цель ссылки «табл. 1».

Деньги считаются десятичными числами, поэтому копейки не теряются. Округление — `round(x, 2)`; правила округления бухгалтерских сумм и НДС — функции `round_money`, `vat`, `with_vat` библиотеки (приложение [«Функции»](generated/functions.md)).

## Таблица без цикла

Если строки — это записи целиком, цикл не нужен:

```prml
|code:
склад = [record(назва="Кабель", к=dec("120")), record(назва="Роз'єм", к=dec("40"))]
|end
|table(data=склад, fields=["назва", "к"], titles=["Найменування", "Кількість"], cols=["*", col("30mm", id="к", type="decimal", align="right")], footer=1):
|:|&(align="right") Разом |& |=(sum(column("к", rows=body_rows())))
|end table
```

## Ячейка из нескольких абзацев

Компактная строка `|:` умещается в одной строке исходника. Для ячейки со списком или несколькими абзацами — развёрнутая форма:

```prml
|table(cols=["35%", "*"], header=0):
|row:
|cell: Обов'язки Виконавця
|cell:
Виконавець зобов'язується:

|- надати послуги в строк;
|- передати звіт.
|end cell
|end row
|end table
```

Компактные и развёрнутые строки можно смешивать в одной таблице.

## Оформление таблицы

Вид таблицы задаёт её стиль: `|table(style="TableCompact", …)`. В наборах стилей комплекта есть готовые: `TableGrid` (по умолчанию), `TableCompact`, `TableNoBorders`; в `business` — `TableServices`, `TableSchedule`, `TableForm`, `TableParties` с заданными ширинами столбцов (свои `cols` таблицы их заменяют). Разовые отличия — аргументы таблицы, строки (`|:(background="#EEEEEE")`) и ячейки (`|&(align="center")`): стиль таблицы → столбец → строка → ячейка, каждый уровень уточняет предыдущий. Линии — `frame=` (рамка) и `rules=` (`"all"`, `"rows"`, `"cols"`, `"none"`).

Таблица внутри раздела с колонками (`|section(cols=2)`) получает ширину колонки.
