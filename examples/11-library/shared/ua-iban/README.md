# ua-iban — IBAN рахунків України для Primula

Бібліотека-зразок до розділу «Бібліотеки» руководства автора (`docs/author/ru/11-libraries.md`): нормалізація, перевірка, групування по чотири знаки й побудова IBAN UA. Лише модуль Primula — без коду Python, працює з будь-якою збіркою транслятора, що підтримує мову 1.1.

- Версія: 0.1.0 (`iban.VERSION`).
- Ліцензія: CC0 (як приклади Primula).
- Джерело правила: ISO 13616 (IBAN), структура IBAN UA — НБУ: `UA`, 2 контрольні цифри, код банку (6), номер рахунку (19).

## Підключення

У корені проєкту документа — символічне посилання (рішення 136; збирання попереджає P2639, що бібліотека поза проєктом):

```sh
ln -s ../shared/ua-iban lib
```

або копія каталогу в `lib/` (тоді документ збирається однаково й без цього каталогу).

```prml
|import("lib/iban")
IBAN: |(iban.grouped(рахунок)) (код банку |(iban.bank_code(рахунок))).
```

## Функції

| Функція | Результат |
| --- | --- |
| `normalized(text)` | без пробілів, великими літерами |
| `problem(text)` | причина українською або `""`, якщо IBAN правильний |
| `is_valid(text)` | `True` / `False` |
| `check(text)` | нормалізований IBAN; неправильний зупиняє збирання з причиною |
| `grouped(text)` | `UA21 3223 1300 0002 6007 2335 6600 1` |
| `bank_code(text)` | код банку (МФО), знаки 5–10 |
| `make(bank, account)` | IBAN з коду банку й номера рахунку |

## Перевірка
