# electronics — номінали й розрахунки

Ряди E3–E96, найближчий номінал, підпис із префіксом, дільник, послідовне і паралельне з'єднання, потужність і допуск.

- Версія: 0.1.0 (`electronics.VERSION`).
- Ліцензія: Apache-2.0 (як код транслятора).
- Кольорової позначки немає: текст IEC 60062 не відкривався, а на переглянутій сторінці таблиці смуг не було.
- Ряду E192 немає: у витязі сторінки список обірвано.

## Підключення

```sh
ln -s <шлях>/electronics lib
```

```prml
|import("lib/electronics")
Номінал |( electronics.fmt_value(dec("4700"), "Ω") ).
```

Модуль не бачить `doc.language`. Мова підпису — аргумент `lang`: `uk` (за замовчуванням), `ru` або `en`.

## Функції

| Функція | Результат |
| --- | --- |
| `series(name)` | мантиси в проміжку [1, 10) |
| `series_problem(name)` | причина або `""` |
| `nearest(value, name, mode="nearest")` | номінал; `mode` — `nearest`, `up` або `down` |
| `nearest_problem(value, name, mode="nearest")` | причина або `""` |
| `fmt_value(value, unit, lang="uk")` | наприклад `4,7 кОм` |
| `fmt_value_problem(value, unit, lang="uk")` | причина або `""` |
| `divider(vin, r1, r2)` | `vin * r2 / (r1 + r2)` |
| `parallel(rs)` | паралельне з'єднання, `rs` — список |
| `series_sum(rs)` | сума послідовних опорів |
| `power(v, r)` | `v² / r` |
| `tolerance_range(value, percent)` | запис `{lower, upper}`; `5` означає ±5 % |

`name` — `E3`, `E6`, `E12`, `E24`, `E48`, `E96`. Постановка писала `parallel(*rs)`; тут список, бо документи цієї збірки передають списки.

Нуль у паралелі — коротке замикання, результат 0, без ділення на нуль. Сума дільника 0 і нульовий опір у `power` — помилка.

`nearest` міряє геометричну відстань: межа між `a` і `b` там, де `v*v = a*b`. Точна рівність лишає менше значення. Точне значення ряду не зсувається в жодному режимі. Вище останньої мантиси результат може стати наступною декадою: для E12 число 9,1 дає 10.

`fmt_value` ставить префікс від піко до тера. Нижче за 10⁻¹² лишається піко і число менше за 1. У підписі не більше шести знаків після коми, хвостові нулі прибрано. Це не округлення до ряду.

## Джерела

Мантиси E24 і E96 — список official values на сторінці Wikipedia «E series of preferred numbers», переглянутій 2026-10-31. E48 на тій сторінці збігається з кожним другим значенням E96, E12/E6/E3 — з кожним 2-м, 4-м і 8-м значенням E24; у файлі `data/series.yaml` лежать E24 і E96, решта збирається кроком. Вісім значень E24 на сторінці навмисно не є найближчим округленням формули: 2,7, 3,0, 3,3, 3,6, 3,9, 4,3, 4,7, 8,2. Їх не перераховано з 10^(k/n).

Текст IEC 60063 не відкривався. E192 не копіювався: рядок списку у витязі обірвано.

Дільник, паралель, сума, потужність і допуск — звичайна арифметика підручника, не цитата зі стандарту. Ділення в трансляторі округлює до 28 знаків; добуток `v * v` лишається точним.
