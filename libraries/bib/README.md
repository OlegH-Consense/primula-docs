# bib — перелік посилань за ДСТУ 8302:2015 і нумеровані посилання в тексті

Джерела — звичайні записи. `registry` один раз фіксує номери й описи; `|bib.cite(reg, "ключ")` пише номер у тексті (`[3]`, `[3, с. 45]`, `[1; 3]`), `|bib.references(reg)` — пронумерований перелік.

- Версія: 0.1.0 (`bib.VERSION`).
- Ліцензія: Apache-2.0 (як код транслятора).
- Друга бібліотека з **командами** (пілот Б напряму 28 плану). Текст ДСТУ 8302:2015 для цієї версії не відкривався — див. «Що звірити». Потрібен транслятор не старіший за 0.4.20.

## Підключення

```sh
ln -s <шлях>/bib lib
```

```prml
|import("lib/bib")
|code:
sources = [
    {"key": "melnyk", "type": "book", "authors": ["Мельник Л. Г."], "title": "Екологічна економіка", "subtitle": "підручник",
     "place": "Суми", "publisher": "Університетська книга", "year": dec("2010"), "pages": dec("346")},
    {"key": "kizima", "type": "article", "authors": ["Кізіма Я. О."], "title": "Біокомп'ютерні технології",
     "journal": "Вісник НТУУ «КПІ»", "year": dec("2013"), "issue": dec("1"), "pages": "55–57"},
]
reg = bib.registry(sources)
|end
Див. |bib.cite(reg, "kizima", pages="56") та |bib.cite(reg, ["melnyk", "kizima"]).

|< Список використаних джерел

|bib.references(reg)
```

Макрос бібліотеки не бачить змінних документа (лише його параметри через `param`), тому реєстр `reg` передається першим аргументом. Щоб не писати його щоразу, документ задає свій короткий макрос:

```prml
|def c(key, pages=None):
  |(bib.cite_text(reg, key, pages))
|enddef
```

і далі `|c("kizima", pages="56")`.

## Джерела

Кожне джерело — запис із полями `key` (унікальний текст), `type` і `title`, решта залежить від типу:

| `type` | обов'язково | необов'язково |
| --- | --- | --- |
| `book` | `publisher`, `year` | `authors`, `subtitle`, `edition`, `place`, `pages` |
| `article` | `journal`, `year` | `authors`, `subtitle`, `volume`, `issue`, `pages` |
| `web` | `url` | `authors`, `subtitle`, `accessed` (рядок «ДД.ММ.РРРР») |
| `act` | `kind` (наприклад, «Закон України») | `date` (рядок), `number`, `url`, `accessed` |

`authors` — список рядків «Прізвище І. Б.» (одне слово прізвища, потім ініціали). `year`, `pages` у книги — числа (`dec("2010")`), сторінки статті — рядок («55–57»).

## Команди і функції

| | Результат |
| --- | --- |
| `registry(sources, order=None, labels={}, responsibility=True)` | запис `{keys, numbers, entries, labels}`; помилка в даних зупиняє збирання повідомленням `bib: <причина>` |
| `\|bib.cite(reg, key, pages=None)` | номер у тексті: `[3]`, `[3, с. 45]`; `key` може бути списком: `[1; 3]` (сторінки — лише для одного джерела) |
| `\|bib.references(reg)` | пронумерований список описів |
| `unused(reg)` | ключі джерел, яких немає в переліку (`order="mention"`: незгадані) |
| `problem(sources)` | причина або `""` |
| `entry(src, labels=LABELS, responsibility=True)` | один опис без номера |
| `number(reg, key)`, `cite_text(reg, key, pages=None)` | номер і текст посилання як значення |

Макрос міг би називатися й `list`: з версії 0.4.20 (рішення 142) назва вбудованої команди для макроса модуля дозволена, але `references` зрозуміліше. Невідомий ключ — помилка `bib: невідомий ключ джерела: …`.

## Порядок і номери

- `order="alphabet"` (за замовчуванням): спочатку кирилиця, потім латиниця; всередині — за алфавітом (`Г < Ґ < Д < Е < Є`) за першим автором (якщо авторів до трьох) або за назвою.
- `order="given"`: у порядку списку.
- `order="mention"`: за порядком **першої згадки в тексті**; у перелік потрапляють лише згадані джерела, `bib.unused(reg)` називає решту. Працює через накопичувач документа (`collect` / `collected`, рішення 143): документ обчислюється двічі, у першому проході номери дорівнюють 0, вивід першого проходу відкидається. Не викликайте `bib.cite_text` / `bib.number` у коді, який може завершитися помилкою до кінця: кожен виклик додає згадку, а послідовність згадок в обох проходах має збігатися (інакше P2640).
- `order` за замовчуванням береться з параметра документа `bib_order` (`params: {bib_order: mention}` у заголовку або проєкті; функція `param`, рішення 144).

## Вигляд опису

- Книга: `Мельник Л. Г. Екологічна економіка : підручник / Л. Г. Мельник. Суми : Університетська книга, 2010. 346 с.` Чотири й більше авторів — запис під назвою: `Назва / А. Б. Один, В. Г. Два, Д. Е. Три [та ін.]. …`. `responsibility=False` прибирає «/ відомості про відповідальність».
- Стаття: `Кізіма Я. О. Біокомп'ютерні технології. Вісник НТУУ «КПІ». 2013. Т. 5, № 1. С. 55–57.`
- Інтернет-ресурс: `Назва. URL: адреса (дата звернення: 05.11.2026).`
- Акт: `Про захист персональних даних : Закон України від 01.06.2010 № 2297-VI. URL: … (дата звернення: …).`
- Слова («с.», «С.», «Т.», «№», «[та ін.]», «дата звернення», «від») замінюються через `labels={"total": "p.", …}`; ключі — у `bib.LABELS`.

## Що звірити

Текст ДСТУ 8302:2015 не відкривався: вигляд описів складено за прийнятою практикою оформлення посилань. Не звірено з текстом: «/ відомості про відповідальність» у книги і його відсутність у статті та вебресурсі, порядок «Місто : Видавець, рік», вигляд акта, коми й крапки в числівнику статті. Прізвища з кількох слів («Жан Поль»), складні заголовки з підзаголовками різних видів, багатотомні видання, дисертації, патенти, стандарти, архівні документи не підтримуються. Бібліотека не є консультацією щодо вимог конкретного закладу.
