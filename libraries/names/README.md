# names — українські прізвища, імена й по батькові

ПІБ у потрібному відмінку («в особі директора Петренка Івана Миколайовича»), ініціали, рядок підпису «Імʼя ПРІЗВИЩЕ», невеликий словник посад. Невірна форма зупиняє збірку; м’яка перевірка повертає причину українською.

- Версія: 0.1.0 (`names.VERSION`).
- Ліцензія: Apache-2.0 (як код транслятора).
- Примітивів транслятора немає.

Апостроф у даних і результатах — U+02BC. На вході `'` (U+0027) і `’` (U+2019) замінюються на нього. Дефіс не прибирається: це частина подвійного прізвища. Пробіли згортаються.

## Підключення

```sh
ln -s <шлях>/names lib      # у корені проєкту документа (попередження P2639)
```

або копія каталогу в `lib/`, або `git submodule add <url> lib/names`.

```prml
|import("lib/names")
в особі |(names.position_case("директор", "gen")) |(names.case("Петренко Іван Миколайович", "gen")).
Підпис: |(names.signature("Петренко Іван Миколайович")).
```

## Функції

| Функція | Результат |
| --- | --- |
| `parse_problem(full)` | причина або `""` |
| `parse(full)` | словник `{last, first, middle}`; нерозбірливий рядок — `fail` |
| `sex(full)` | `"m"` / `"f"` / `None` |
| `case_problem(full, which, sex=None, exceptions=None)` | причина або `""` |
| `case(full, which, sex=None, exceptions=None)` | ПІБ у відмінку; невідома форма — `fail` |
| `initials_problem(full, style="before")` | причина або `""` |
| `initials(full, style="before")` | «І. М. Петренко»; `style="after"` — «Петренко І. М.» |
| `signature_problem(full)` | причина або `""` |
| `signature(full)` | «Іван ПЕТРЕНКО» |
| `position_problem(text, which)` | причина або `""` |
| `position_case(text, which)` | посада зі словника; невідома — `fail` |

`which` — `"gen"`, `"dat"`, `"acc"`, `"ins"`, `"loc"`, `"voc"`. Називний не приймається: його вже має автор.

Два слова — прізвище й ім’я, `middle` порожній. Три — прізвище, ім’я, по батькові. Одне слово: «потрібні прізвище й імʼя». Більше трьох: «забагато слів». Латиниця, цифри, не рядок і порожній рядок — свої причини, не чужа форма.

`sex=` замінює здогад за ім’ям, коли по батькові немає. Якщо по батькові суперечить `sex=`, причина «по батькові суперечить аргументу sex». Нерозпізнане по батькові (Ілліч) — причина, навіть коли `sex=` передано.

`exceptions=` — словник автора: називний → `{gen, dat, acc, ins, loc, voc}`. Він головніший за файл для цього написання. Неповний рядок — «неповна парадигма винятку». Пошук точний за написанням: `заєць` не збігається з `Заєць`.

## Правила

Текст правопису читано на slovnyk.ua 31.10.2026 (видання 2019). Де правопис дає два закінчення, бібліотека бере перше.

Чоловічі прізвища II відміни на твердий приголосний: родовий `-а`, давальний і місцевий `-ові` (таблиця Олег у § 143, не загальне `-і`), орудний `-ом`, кличний за § 87. Суфікси `-ко`, `-ик`, `-ок`, `-ук`, `-юк`, `-ек` у кличному дають `-у` без `к→ч` (Максименку, Гашеку). Без суфікса `г/к/х` дають `-е` зі зміною `г→ж`, `к→ч`, `х→ш` (Вовче). Інший твердий — `-е` (Морозе). М’який і на `-й` — `-ю`. Мішаний на `ж` — `-е`; прізвище на `ч/ш/щ` — `-у` (Кулішу), ім’я — `-е`.

Родовий чоловічих прізвищ II відміни завжди `-а/-я` (§ 142, примітка 2). `г/к/х` змінюються на `з/ц/с` лише перед закінченням `-і`.

`-ець` у непрямих відмінках втрачає `-е-`, крім Швець, Жнець, Чернець (Швеця). Після `л` пишеться м’який знак (Каролець — Карольця, Малець — Мальця). Після губного, `р`, `н` і решти приголосних м’якого знака немає (Моравець — Моравця; зразок загальних імен: хлопець — хлопця, кінець — кінця). Кличний `-ець` — `-ю` без `ц→ч` (Швецю), не шевче/кравче (§ 87.3).

Прикметник `-ий`: `-ого/-ому/-им`, кличний дорівнює називному. М’який прикметник лише на `-ній` (Крайній — Крайнього). Прізвище на `-ій`, яке не кінчається на `-ній`, — іменник (Балій — Балія). Жіноче `-ська/-цька/-зька` — прикметник (Кобилянської).

Чоловічі присвійні `-ов/-ев/-єв/-ів/-їв`: давальний `-у`, орудний `-им`, місцевий `-і`, кличний `-е` (Павлов). `-ин/-ін/-їн`: давальний `-ові`, орудний `-им` (Гаршин), крім `-анин/-янин` — іменник II, орудний `-ом` (Лучканином). Неслов’янський орудний `-ом` (Дарвіном, Чапліном, § 85) сам не розпізнається.

Жіноче прізвище на приголосний і на `-о`, зокрема `-ів`, не відмінюється (§ 142, примітка 2). Жіноче ім’я на приголосний — III відміна (Любов — Любові, Любовʼю). `-а/-я` — I відміна для обох родів: жіноче Павлова дає Павлови, не прикметникове Павлової.

Подвійне прізвище відмінюється кожною частиною (Квітки-Основʼяненка). Порожня частина після дефіса — причина.

По батькові: чоловіче родовий `-а`, давальний, місцевий і кличний `-у`, орудний `-ем` (Васильовича, Васильовичу, Васильовичем). Жіноче `-івна` і `-ївна` (Андріївна) — тверда I відміна. `-йович` уже закінчується на `-ович`.

Стать: по батькові головне (`-ович/-евич/-йович` — чоловік, `-івна/-ївна` — жінка). Без нього чоловічі `-а/-я` зі списку Микола, Ілля, Кузьма, Хома, Лука, Сава, Ярема; жіночі на приголосний зі списку Любов, Адель, Нінель, Рахіль, Есфір; решта `-а/-я` — жінка; решта на приголосний, `-о`, `-й` — чоловік.

Посада — окремий словник у нижньому регістрі (`data/positions.yaml`), не рушій імен. Збіг після згортання пробілів і `lower()`. Невідома посада — «немає в словнику посад». Місцевий осіб у словнику — `-ові`, як у власних іменах.

Винятки, які закінчення не вгадують, лежать у `data/exceptions.yaml`. Рядок з `role: ""` діє на будь-яке слово, `"first"` — лише на ім’я, `"last"` — лише на прізвище. Яків як ім’я (Якова) не чіпляється до прізвища Яків (Яківа: неперелічений `-ів` зберігає `і`).

## Чого немає у 0.1.0

- Російські імена в українському тексті. Постановка лишає це відкритим; Ілліч дає причину, не форму.
- Жіночі `-ова/-ева/-іна` як прикметники (Павлової). Тут вони I відміна (Павлови). Хто потребує прикметника, передає `exceptions=`.
- Неслов’янський орудний `-ом` у `-ов/-ин` (Дарвіном, Чапліном) сам не вибирається.
- Невідмінюване іншомовне `-о` (Гюго) не відрізняється від українського прізвища на `-о`: чоловіче відмінюється.
- Після випадіння `-е-` у `-ець` м’який знак пишеться лише після `л`. Форма, якій потрібен `ь` після іншого приголосного, іде у винятки.
- Інші вставні голосні та чергування `і/о/є` з `й`, крім перелічених рядків файлу, не вгадуються. Яків як ім’я — рядок файлу; Авенір, Лаврін, Олефір не чергуються.
- Неперелічений `-ів` зберігає `і` (дужковий варіант Коваліва не видається). Ковалів, Прокопів, Кирчів — перший, чергований варіант.
- Жіноче ім’я на приголосний поза списком `_FEM_C` без по батькові читається як чоловіче. Тоді передають `sex="f"`.
- Чоловіче прізвище Любов — виняток II відміни, щоб літери `-ов` не дали орудного Любовим. Жіноче ім’я Любов лишається III відміною.
- Волошин: давальний `-у` (перший у примітці § 83), місцевий `-і` (перший у таблиці `-ин`). Повний порядок § 86 не переписувався.
- Вовк — Вовче випливає з правила `к→ч` без суфікса, це не окремо звірена парадигма прізвища.
- Текст ДСТУ 4163:2020 не відкривався. Форму підпису «Імʼя ПРІЗВИЩЕ» взято з постановки.

## Джерела

- Постановка `libraries/names.md` цього каталогу: склад функцій, апостроф U+02BC, підпис, приклад «в особі директора Петренка Івана Миколайовича».
- Український правопис 2019, §§ 142, 143, 85, 87, 146 — відтворення на slovnyk.ua (`prav_par=142`, `143`, `87`), читане 31.10.2026. Це текст видання 2019. pravopys.net у цій сесії не брався за джерело 2019: там видання 2015. Офіційні PDF mon.gov.ua і mova.gov.ua у пошуку було видно; робочі таблиці взято з відтворення slovnyk.ua.
