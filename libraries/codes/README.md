# codes — штрихкоди й контрольні цифри

Контрольні цифри EAN-13, ISBN і Луна, а також SVG штрихкоду EAN-13 для `|img(svg=…)` і `|figure(svg=…)`.

- Версія: 0.1.0 (`codes.VERSION`).
- Ліцензія: Apache-2.0 (як код транслятора).
- Code 128 у цій версії немає: таблиці наборів ISO/IEC 15417 у сесії не відкривались.
- EAN-8 немає. Тиха зона — параметр, не мінімум зі стандарту.

## Підключення

```sh
ln -s <шлях>/codes lib
```

```prml
|import("lib/codes")
|img(svg=codes.ean13_svg("5901234123457", quiet=7))
```

Номер `5901234123457` — ілюстрація зі сторінки опису EAN-13, не товар бібліотеки. `4006381333931` у тесті — приклад Stabilo з тієї самої сторінки. `0-306-40615-2` і `79927398713` — поширені навчальні приклади, не реквізити.

## Функції

| Функція | Результат |
| --- | --- |
| `ean13_check(digits)` | контрольна цифра тіла з 12 цифр |
| `ean13_check_problem(digits)` | причина або `""` |
| `ean13_problem(code)` | причина для повного коду або `""` |
| `is_ean13(code)` | `True` / `False` |
| `ean13_modules(code)` | 95 знаків `0`/`1`, без тихої зони |
| `ean13_svg(code, height="15mm", module="0.33mm", quiet=0, text=True, font="Liberation Sans")` | SVG |
| `ean13_svg_problem(...)` | причина або `""` |
| `luhn_check(digits)` | контрольна цифра тіла |
| `luhn_check_problem(digits)` | причина або `""` |
| `luhn_problem(code)` | причина або `""` |
| `is_luhn(code)` | `True` / `False` |
| `isbn_problem(text)` | причина або `""` |
| `is_isbn(text)` | `True` / `False` |
| `isbn13(text)` | 13 цифр; ISBN-10 отримує префікс `978` і нову контрольну цифру |

Пробіли й дефіси прибираються. Число замість рядка не приймається: зникли б початкові нулі. Місця дефісів ISBN не перевіряються — таблиць діапазонів груп у 0.1.0 немає.

`quiet` — ціле число модулів з кожного боку. За замовчуванням 0. `module` і `height` — довжини (`"0.33mm"`, `"15mm"`). `0.33mm` — розмір малюнка, не перевірений мінімум друку. Підпис — один рядок із 13 цифр під штрихами, не розкладка людиночитаних цифр GS1.

## Перевірки

EAN: вага 1 на непарній позиції зліва і вага 3 на парній. Контрольна цифра — `(10 - сума mod 10) mod 10`. Для тіла з 12 цифр це те саме, що вага 3 на непарних позиціях справа.

Малюнок: `101`, шість лівих цифр (L або G за першою цифрою), `01010`, шість правих цифр завжди R, `101`. Перша група завжди починається з L.

Лун: зправа кожна друга цифра подвоюється; цифра понад 9 зменшується на 9. Контрольна цифра в кінці номера сама не подвоюється. Для тіла без неї подвоюється якраз права цифра тіла.

ISBN-10: ваги 10…1, `X` = 10, сума ділиться на 11. ISBN-13 перевіряється тією самою формулою, що EAN-13. Префікс `978`/`979` окремо не вимагається.

## Джерела

Кодування L/G/R і вибір набору за першою цифрою — сторінка Wikipedia «International Article Number», переглянута 2026-10-31. Текст ISO/IEC 15420 не відкривався. Сторінка GS1 про ручний розрахунок контрольної цифри в цій сесії віддала відмову доступу; ваги 1/3 взято з тієї самої сторінки Wikipedia і з постановки. Приклади сторінки: `5901234123457` (контрольна 7) і `4006381333931` (контрольна 1). Тиху зону в модулях та сторінка не називає.

Лун і ISBN: тексти ISO/IEC 7812 і ISO 2108 не відкривались. Правило Луна — те, що назване в постановці; для `7992739871` контрольна цифра виходить 3, повний `79927398713` ділиться на 10. ISBN-10 `0-306-40615-2` дає суму, кратну 11; з префіксом `978` виходить `9780306406157`.
