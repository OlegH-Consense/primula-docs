# charts — діаграми SVG

Стовпці, лінія і круг для `|figure(svg=…)` / `|img(svg=…)`. Малюнок детермінований: ті самі аргументи дають той самий рядок.

- Версія: 0.1.0 (`charts.VERSION`).
- Ліцензія: Apache-2.0 (як код транслятора).
- Ширини тексту в трансляторі немає. Підпис під стовпцем ставиться по центру слота; довгі підписи можуть налізти один на одного. Шрифт передає автор (`font`, за замовчуванням `Liberation Sans`).

## Підключення

```sh
ln -s <шлях>/charts lib
```

```prml
|import("lib/charts")
|figure(svg=charts.bar(рядки, "назва", "сума", width="120mm", height="70mm")):
Продажі
|end figure
```

## Функції

| Функція | Результат |
| --- | --- |
| `bar(rows, x, y, width="120mm", height="70mm", title=None, colors=None, stacked=False, font="Liberation Sans")` | стовпці |
| `line(...)` | ламана |
| `pie(rows, label, value, width="80mm", height="80mm", ...)` | круг |
| `chart_problem(rows, x, y)` | причина або `""` |
| `pie_problem(rows, label, value)` | причина або `""` |

`y` — ім'я поля або список полів. Кілька полів у `bar` стоять поруч; `stacked=True` кладе їх один на одного і не приймає від'ємне значення. `line` малює по ламаній на поле. `pie` бере одне поле.

Вісь включає нуль. Крок — 1, 2 або 5, помножені на степінь десяти, близько чверті розмаху. Підписи осі йдуть через `num`, тож залежать від мови документа. Координати в SVG — завжди з крапкою і двома знаками.

Кольори за замовчуванням розрізняються і в сірому: `#222222`, `#6e6e6e`, `#b0b0b0`, `#3f6b4e`, `#8a6232`, `#2c4a6e`.

Елементи лише `rect`, `line`, `polyline`, `path`, `text`. Без скриптів і зовнішніх посилань. Повне коло — два півкола: одна дуга SVG не замикає 360°.

## Джерела

Це побудова малюнка, не вимірювальний стандарт. Крок осі 1–2–5 — звичайна практика шкал. Перевірено 31.10.2026 тим, що SVG проходить `primula check` (P6110–P6112) у `|figure`. Окремий ДСТУ на вигляд діаграми не відкривався.

## Перевірка

```sh
PRIMULA=primula ./run-tests.sh
```

`demo/lib` → `../.`. Попередження P2639 очікуване. Вигляд у PDF варто глянути очима: перевірка тут структурна.
