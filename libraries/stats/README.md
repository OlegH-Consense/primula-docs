# stats — зведення для звіту

Медіана, мода, дисперсія, перцентиль і ковзне середнє. Середнє вже є в ядрі (`avg`); ця бібліотека його не замінює.

- Версія: 0.1.0 (`stats.VERSION`).
- Ліцензія: Apache-2.0 (як код транслятора).

## Підключення

```sh
ln -s <шлях>/stats lib
```

```prml
|import("lib/stats")
Медіана |( num(stats.median(ряд), digits=2) ).
```

## Функції

| Функція | Результат |
| --- | --- |
| `values_problem(xs)` | причина або `""`: порожній список, `None`, не число |
| `median(xs)` | середина; для парної кількості — середнє двох середин |
| `mode(xs)` | найчастіше значення; за рівності частот — найменше |
| `variance(xs, sample=True)` | дисперсія: ділення на `n−1` або на `n` |
| `variance_problem(xs, sample=True)` | причина або `""` |
| `stdev(xs, sample=True, digits=10)` | стандартне відхилення, `decimal` |
| `percentile(xs, p, method="inclusive")` | лінійний перцентиль, `p` від 0 до 100 |
| `percentile_problem(...)` | причина або `""` |
| `moving_average(xs, n)` | середні вікон, довжина `len−n+1` |
| `describe(xs, digits=10)` | `{n, min, max, mean, median, stdev}` |

`stdev` бере `math.sqrt`. Корінь — `float`, тож результат — `dec` від найкоротшого запису цього `float`, далі `round` (половина від нуля) до `digits` знаків. Для одного значення вибіркова дисперсія не рахується; генеральна дорівнює нулю.

`percentile` з `method="inclusive"` — це PERCENTILE.INC табличного процесора: ранг `p/100×(n−1)`, лінійна інтерполяція між сусідніми значеннями. Інших методів у 0.1.0 немає.

## Джерела

Формули вибіркової дисперсії (`/(n−1)`) і генеральної (`/n`), медіани й моди — звичайні означення, не норма. Перцентиль звірено з означенням PERCENTILE.INC (ранг від 0 до `n−1`) 31.10.2026 на наборі 1, 2, 3, 4: 25-й дає 1,75, 40-й — 2,2, 50-й — 2,5. Окремий текст ДСТУ під цю бібліотеку не відкривався.
