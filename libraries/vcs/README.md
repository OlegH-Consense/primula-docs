# vcs — аркуш реєстрації змін

Таблиця змін технічного документа з історії Git. Модуль Git не читає і програм не запускає. Скрипт пише JSON, документ передає його в `changes`.

- Версія: 0.1.0 (`vcs.VERSION`).
- Ліцензія: Apache-2.0 (як код транслятора).
- Це не форма ДСТУ і не форма ЄСКД. Текст стандарту на аркуш реєстрації змін не відкривався. Колонки — власні для цієї бібліотеки.

## Підключення

```sh
ln -s <шлях>/vcs lib
```

У корені git-репозиторію документа, перед збиранням:

```sh
/шлях/до/vcs/tools/export-changes.sh doc.prml > data/changes.json
```

```prml
|import("lib/vcs")
|code:
rows = vcs.changes(load_json("data/changes.json"))
|end
|table(data=rows, fields=["number", "date", "author", "sections", "reason"], titles=["№", "Дата", "Автор", "Розділи", "Підстава"], cols=["12mm", "28mm", "40mm", "30mm", "*"], header=1):
|end table
```

`data/changes.json` лежить у проєкті документа. Для одного й того самого файлу документ збирається однаково.

## Функції

| Функція | Результат |
| --- | --- |
| `changes(data)` | рядки для `\|table(data=…)` |
| `changes_problem(data)` | причина або `""` |

Кожен рядок має рядкові поля `number`, `date`, `author`, `sections`, `reason`, `files`, `hash`. Номер — текст, не `decimal`. Порядок — за номером зміни, не за датою коміту.

Порожній список і історія без жодної розміченої зміни дають причину «історія змін порожня».

## Розмітка коміту

Скрипт вивантажує коміти, які зачіпають зазначені шляхи. Модуль лишає лише ті, чий перший рядок має вигляд:

```text
Зміна 2: уточнено таблицю

Розділи: 1.2, 4
```

`N` — ціле від 1. Підстава після двокрапки не порожня. Рядки `Розділи:` необов'язкові; якщо їх кілька, тексти з'єднуються через кому. Коміт без префікса `Зміна ` пропускається. Рядок, який починається з `Зміна `, але не розбирається, — помилка, а не пропуск. Однаковий номер у двох комітах — помилка.

`files` — імена файлів коміту через кому. `hash` — повний хеш, як його записав скрипт. `date` — дата автора у вигляді `YYYY-MM-DD`.

## Скрипт

`tools/export-changes.sh` потребує `git` і `python3`. Без аргументів вивантажує всі коміти. Шлях обмежує журнал так само, як `git log -- шлях`, і рахується від поточного каталогу. Повідомлення з символом U+001E скрипт розріже неправильно; у звичайному тексті його немає.

Каталог цієї бібліотеки сам не є git-репозиторієм. Скрипт перевірено в окремому тимчасовому репозиторії.
