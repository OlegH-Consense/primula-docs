# Шаблоны Primula Studio

Шаблоны меню **Файл → Создать** и контекстного меню панели «Файлы» (этап 14.9). Встроенные шаблоны лежат здесь и вкомпилированы в Studio как ресурсы; свои шаблоны пользователь кладёт в `~/.config/primula-docs/templates/<id>/` (**Файл → Создать → Открыть папку шаблонов пользователя**). Шаблон пользователя с тем же `id`, что встроенный, заменяет его.

## Состав шаблона

Каталог `<id>/` с файлом `template.json` и файлами шаблона:

```json
{
 "kind": "document",
 "order": 10,
 "title": {"en": "Simple document", "uk": "Простий документ", "ru": "Простой документ"},
 "description": {"en": "…", "uk": "…", "ru": "…"},
 "files": [
  {"from": "doc.prml", "to": "{{name}}.prml", "open": true},
  {"from": "intro.f.prml", "to": "fragments/{{name}}-intro.f.prml"}
 ],
 "strings": {"en": {"intro": "Short introduction."}, "uk": {"intro": "Короткий вступ."}, "ru": {"intro": "Краткое введение."}}
}
```

| Поле | Значение |
| --- | --- |
| `kind` | `document`, `fragment`, `module`, `styles`, `project`, `order` — раздел меню «Создать» |
| `order` | порядок в списке шаблонов вида |
| `title`, `description` | название и описание на en/uk/ru (нет языка — английский) |
| `files` | что копировать: `from` — файл шаблона, `to` — путь создаваемого файла относительно места (для проекта и заказа — относительно нового каталога), `open` — открыть вкладкой после создания |
| `strings` | тексты по языкам для подстановки `{{s.<ключ>}}` |

## Подстановки

В путях `to` и в текстах файлов:

| Подстановка | Что даёт |
| --- | --- |
| `{{name}}` | имя из диалога (основа имени файла, имя каталога проекта или заказа) |
| `{{title_yaml}}` | заголовок из диалога (пусто — имя), экранированный для строки YAML в двойных кавычках |
| `{{lang}}` | язык документа: `uk-UA`, `ru-RU`, `en-US` — по выбранному языку текстов |
| `{{date}}`, `{{year}}` | текущая дата (ISO) и год |
| `{{s.<ключ>}}` | строка `strings` выбранного языка |
| `{{base}}`, `{{targets}}`, `{{styles}}`, `{{order_yaml}}` | только для `order`: путь к файлу базового проекта, строки целей YAML (документы базового проекта, кроме его первой цели), список модулей стилей (с `std/styles/default`, если базовый проект стилей не перечисляет), содержимое `orders/sample.yaml` базового проекта (или минимальный образец) |

Существующие файлы не перезаписываются: диалог показывает создаваемые файлы и не даёт создать, если какой-то из них уже есть.

## Встроенные шаблоны

| Вид | Шаблоны |
| --- | --- |
| Документ | простой; договор (разделы и пункты, стороны — параметры, ссылки, реквизиты, приложение со спецификацией); документ из фрагментов (два фрагмента, параметр и части); настанова (оглавление, предупреждения, таблица с подписью, сокращения, варианты `has()`); деловое письмо |
| Фрагмент | простой; с параметрами и частями `|part` |
| Модуль | модуль определений (макрос и значение для `|import`) |
| Модуль стилей | локальный слой; деловые стили с профилем, нумерацией, типографикой и колонтитулом |
| Проект | с одним документом; с пакетной сборкой по CSV; договор и заказы |
| Проект заказа | `orders/<имя>/` с `extends`, своим `order.yaml` и `placeholders("final")` |

Тест Studio `everyTemplateCreatesFilesTheTranslatorAccepts` разворачивает каждый шаблон на трёх языках и проверяет его транслятором (`primula check --strict`; допускаются только заполнители `|?{…}` в бланках).
