# Дополнительные проверки на старых системах

Debian 12 (Qt 6.4) и Debian 13 (Qt 6.8) проверены 22.10.2026: сборка `build-debian.sh`, комплект `make-distribution.sh`, установка, запуск Studio, сборка документа. Разработка ведётся на openSUSE Tumbleweed с Qt 6.11, поэтому на старых системах стоит при случае посмотреть места, где версии Qt и пакеты различаются. Это не обязательные проверки; найденное записывается в список замечаний (`primula-remarks.md` в корне дерева).

| Что проверить | Как | Почему может отличаться |
| --- | --- | --- |
| Номера страниц в оглавлении и ссылках «стор. N» в PDF | собрать документ с `\|toc` и `\|@("id", "page")` с `--pdf`; в сообщениях не должно быть P8008 | номера заполняет мост UNO LibreOffice: пакет `python3-uno` (Debian), `libreoffice-pyuno` (openSUSE); `build-debian.sh --install-deps` ставит его с 0.1.0.dev37 (22.10.2026); при установке пакетов раньше — доставить вручную |
| Панель PDF | F4 — переход к странице заголовка под курсором и обратно; закладки; масштаб после пересборки | QtPdf в 6.4 — самая ранняя поддерживаемая версия (`QPdfView`, `QPdfBookmarkModel`) |
| Перевод интерфейса | запустить `LANG=uk_UA.UTF-8 primula-studio` и `LANG=ru_RU.UTF-8 primula-studio` (язык берётся из системы, если в настройках нет `ui/language`) | файлы `.qm` устанавливаются в `share/primula-studio/translations` |
| Значки | значки панелей и меню видны (не пустые квадраты) | в Debian 13 модуль SVG значков — отдельный пакет `qt6-svg-plugins` |
| Шрифты наборов стилей | собрать `examples/08-styles` с `--pdf`; шрифты Liberation Serif/Sans в PDF (`pdffonts файл.pdf`) | пакет `fonts-liberation` (Debian), иначе LibreOffice подставит другой шрифт и вёрстка сдвинется |
| Подсказки и дополнение | наведение на команду, `Ctrl+Space`, F1 на конструкции | всплывающие окна и `QTextDocument::setMarkdown` в старых Qt рисуют иначе |
| Справка | F1 вне конструкции: текст начинается с заголовка, служебных комментариев (`<!-- … -->`) не видно; Справка → Шпаргалка команд (PDF) | Markdown-читатель Qt 6.4 |
| AI-запросы | если установлен Codex CLI или Claude CLI — запрос по выделению | версии CLI и их пути в Debian |
| Консоль вычислителя | открыть, вычислить `money(dec("1500"), "UAH")` | отдельный процесс `primula console --json` с системным Python 3.11 (Debian 12) |
| Python 3.11 | `primula --version`; сборка примеров `examples/run.sh --pdf` | Debian 12 — Python 3.11, нижняя граница транслятора |
